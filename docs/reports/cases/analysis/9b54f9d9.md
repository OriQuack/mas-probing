# 9b54f9d9 (음식 중복 목록 + CATEGORIES XML, level 3) 심층 분석

## 4.1 Task와 의도된 풀이

- **질문**: "Which of the text elements under CATEGORIES in the XML would contain the one food in the spreadsheet that does not appear a second time under a different name?"
- **첨부 zip**
  - `food_duplicates.xls`: 11×9 = 99개 이름. 49쌍 + 1개 구조.
  - `CATEGORIES.xml`: Word 2003 XML. 본문 `CATEGORIES { "Fruits", "Vegetables", "Meats", "Cheeses", "Sweets", "Legumes", "Drinks", "Seasonings", "Sandwiches", "Soups and Stews", }`.
- **gold = Soups and Stews**
  - annotator 풀이: 다른 이름으로 중복된 것을 지워 감("clam = geoduck, sandwich = hoagie, dried cranberries = craisins..."). 남는 것은 turtle soup이고, 그 범주는 Soups and Stews.
  - annotator의 대응은 **느슨한 대응**임. clam/geoduck, sandwich/hoagie는 동의어가 아니라 상위어/하위어 관계임.
  - 99 = 49×2 + 1이라는 구조가 의도된 짝짓기를 강제함. pumpkin/squash, agave/nectar, peas/sugar snaps, bonbon/candy, oat cereal/granola, pickle/relish, goat meat/mutton 등도 짝으로 세야 함.
- **틀릴 수 있는 곳**
  1. "under a different name"을 엄격한 동의어(같은 음식의 다른 이름)로 읽는 것. 이렇게 읽으면 상위어/하위어 쌍이 모두 짝이 되지 못하고, "unmatched가 여럿이라 정할 수 없다"로 감.
  2. 짝을 파일 안의 표시로만 인정하는 것("only when supported by the data"). 파일에는 짝 표시가 없음.
  3. XML은 범주 이름만 있고 음식→범주 배정은 없음. turtle soup → Soups and Stews는 의미로 추론해야 함. Meats와 헷갈릴 여지는 작음.
  4. 답 형식: `"Soups and Stews",`(따옴표와 쉼표 포함)로 낸 run도 정답 처리됐음(정규화).
- 15 run 모두 turtle soup을 후보로 찾았음. 갈린 곳은 1번(엄격한 기준) 하나뿐이고, 그 기준이 refiner rewrite와 orchestrator re-check를 통해 들어온 경우에만 실패했음.
