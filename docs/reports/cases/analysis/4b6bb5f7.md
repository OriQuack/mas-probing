# 4b6bb5f7 — Doctor Who S9E11 "Heaven Sent" 첫 scene heading의 setting

## 4.1 과제와 의도된 풀이

- 질문: "What is this location called in the official script for the episode? Give the setting exactly as it appears in the first scene heading."
- Gold: `THE CASTLE`. BBC Writers' Room PDF의 첫 scene heading은 `INT. THE CASTLE - DAY`이고, annotator는 그중 location(setting) 부분만 답으로 적었다.
- 과제 문구 분석: "What is this **location** called"와 "Give the **setting** exactly as it appears in the first scene heading"는 둘 다 slugline의 장소 요소를 가리킨다. Slugline은 `INT./EXT.` + setting/location + time of day로 이루어진다. "exactly as it appears"는 대문자와 표기를 그대로 지키라는 요구이지, heading 전체를 내라는 요구가 아니다. 과제 텍스트만으로 `THE CASTLE`(대문자 유지)이 결정된다. 덧붙여 scorer는 대소문자를 무시하므로 `The Castle`도 통과한다.
- 함정: "exactly as it appears in the first scene heading"을 "heading 전체를 그대로"로 읽어 `INT. THE CASTLE - DAY`를 내는 것. 이것이 유일한 실패 원인이다. 출처 찾기는 모든 run에서 쉬웠다(BBC PDF를 1-3회 tool 호출로 읽음).
