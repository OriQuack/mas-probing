## 4.1 Task와 의도된 풀이

- 단서: tank 1, healer 1, DPS 3. plate 2, cloth 2. tank와 healer가 holy spell. ice와 fire를 서로 다른 DPS가 씀. 파티의 bear가 boss를 공격. Metamorphosis 시전. "Kilt of the Forgotten One"이 떨어졌지만 "no one can use it". 직업은 모두 다름.
- annotator 경로: Kilt는 leather이고 WotLK에 추가된 item(Herald Volazj, Ahn'kahet) → "just released" dungeon이면 시대는 **WotLK**(step 8). 그 시대 직업에서 Evoker/DH/Monk 제외 → holy = Paladin(tank) + Priest(healer) → Metamorphosis = Warlock(cloth 2번째) → leather 착용 직업 없음이므로 bear는 Druid가 아니라 **Hunter의 pet** → plate 2번째는 DK 또는 Warrior, ice는 Frost DK.
- 실수 지점(사전에 예측 가능한 것):
  1. **시간 기준**: "just released"를 현재(run date)로 읽으면 2026년 dungeon을 찾아 헤매게 됨. 의도된 읽기는 item이 나온 시대(WotLK).
  2. **"no one can use it"의 의미**: 의도는 "leather가 주 armor인 직업이 파티에 없다"(앞 단서 "plate wearers/cloth wearers"와 같은 primary-armor 어법). WotLK 규칙을 문자 그대로 적용하면 plate/mail 직업도 leather를 착용할 수 있으므로 어떤 2-plate 파티도 이 단서를 만족할 수 없음 → 단서가 변별력을 잃음.
  3. **bear = Druid 대 Hunter pet**: 가장 쉬운 연상은 Druid. Druid로 가면 plate/cloth 개수(1 plate, 3 cloth)가 깨짐.
  4. **ice = DK 대 Warrior+Hunter Frost Trap**: annotator step 19는 "Hunters ... cannot cast Frost abilities"라고 하지만 WotLK Hunter에는 Frost Trap이 있음. 그래서 Warrior 대안이 문자 그대로는 완전히 배제되지 않음(rA c2 r1 d1, rB c3 d1 worker도 이를 지적). gold는 "ice를 쓰는 DPS 직업 = Frost DK"라는 자연스러운 읽기에 의존함. 채점 문제로 보지는 않지만 gold의 유일성 논증에 약점이 있다는 점은 기록해 둠.
