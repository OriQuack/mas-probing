# ded28325 — Caesar cipher 해독 ("Zsmxsm sc sx Zyvilsec Zvkjk.")

## 4.1 과제와 의도된 풀이

- 질문: 친구가 준 Caesar cipher 메시지 "Zsmxsm sc sx Zyvilsec Zvkjk."를 해독하라. 무엇이라고 쓰여 있는가?
- Gold: `Picnic is in Ploybius Plaza.`
- 실제 해독: 각 문자를 10칸 뒤로 이동하면 `Picnic is in Polybius Plaza.`가 된다. 직접 계산해 확인했다: Z→P, y→o, v→l, i→y, l→b, s→i, e→u, c→s 이므로 "Zyvilsec"은 "Polybius"다. 암호문에서 "Ploybius"를 만들 수 있는 Caesar 이동은 없다. "Ploybius"가 되려면 2·3번째 글자가 l, o여야 하는데, 이는 암호문의 y, v(→o, l)와 순서가 반대다. Gold는 **철자 오류**(Polybius → Ploybius)다. Annotator 단계는 brute-force 결과를 보고 "picnic" 맥락에 맞는 것을 고르라고만 했고, 특정 철자를 근거로 들지 않는다.
- Scorer: `normalize_str`은 소문자화, 공백 제거, ASCII 구두점 제거 후 비교한다. `picnicisinpolybiusplaza` ≠ `picnicisinploybiusplaza`이므로 오답 처리된다. scorer로 직접 확인했다.
