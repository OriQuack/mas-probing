## 4.1 과제와 의도된 풀이

- 질문: James(Major Hardware 채널)가 season 4에서 테스트한 "Cheater"와 "Cheater Beater"의 CFM을 "CFM number for Cheater, CFM number for Cheater beater" 형식으로 보고하라. 형식 템플릿의 각 원소는 "CFM number", 즉 **숫자**다. 정밀도(소수 자릿수)는 과제가 지정하지 않는다.
- Gold: `101.376, 84.348`. Annotator는 S4E6 영상의 timestamp 485 화면 표(season 4 결과표)에서 CFM 열 값을 그대로 읽었다(S4E1 Cheater 101.376, S4E6 Cheater Beater 84.348).
- 함정:
  1. 영상 화면 표는 워커가 볼 수 없다(YouTube 페이지 텍스트는 footer만 반환). 접근 가능한 대체 출처는 Reddit에 링크된 팬 제작 Google Sheet인데, **CSV export는 셀의 표시 형식(소수 둘째 자리)을 적용해 `101.38`, `84.35`를 내보낸다**. 저장된 값(101.376, 84.348)은 XLSX export에서만 보인다. 참고로 CFM = FPM × 0.132 (768 × 0.132 = 101.376, 639 × 0.132 = 84.348).
  2. 영상 transcript는 FPM(ft/min)만 말하므로 "CFM 없음"으로 결론 내리기 쉽다.
  3. S4E10의 "Neater Cheater Beater"(87.78 CFM)와 혼동, Season 4 finale의 Cheater 재측정(102.43, approximated)과 혼동.
  4. 단위: GAIA 형식 규칙상 숫자에 단위를 붙이면 안 된다. Scorer 확인 결과 `101.376 CFM, 84.348 CFM`도 오답, `101.38, 84.35`도 오답(정확한 수치 비교).
