# f3917a3d — Wikipedia "Antidisestablishmentarianism" 문서의 생성부터 2023년 6월까지 편집 수

## 4.1 과제와 의도된 풀이

- 질문: 영어 Wikipedia 문서 "Antidisestablishmentarianism"에 생성 시점부터 2023년 6월까지 몇 번의 편집이 있었나.
- 정답(gold): `2732`.
- annotator 경로: 문서 history를 500개 단위로 넘기며 세기 → 500×5 + 마지막 페이지 232 = 2732. annotator는 "no edits appear to have been made after May of 2023"라고 적음.
- 실행에서 확인된 사실: 컷오프 이전 마지막 리비전은 2023-05-16(rev 1155041522), 다음 리비전은 2023-07-15(rev 1165536378). 따라서 "until June"을 6월 1일 전으로 읽든 6월 30일까지로 읽든 답은 같다(draft의 "end of June 30" 해석은 무해).
- 실수 가능 지점:
  1. API 페이지네이션 실수(rvcontinue 오용; A d0에서 실제로 발생 후 자가 수정).
  2. 출처마다 총계가 다름: Wikipedia `action=info`의 "Total number of edits" = **2,822**(c3 probe r2 관찰), XTools articleinfo API의 `"revisions":2821`, XTools 기간 지정 pageinfo(2001-09-28~2023-06-30) = **2,732**, MediaWiki revisions API 직접 열거 = 2,732(컷오프 이전) + 90(이후). 즉 XTools articleinfo 총계만 1이 낮다(원인은 트레이스로 판정 불가; XTools 페이지는 초기 MediaWiki 저장 방식 때문에 "approximate"라고 경고).
  3. "총계 − 컷오프 이후 개수" 식의 간접 계산은 총계 출처가 위의 불일치를 품고 있으면 1만큼 틀린다 — 이번 실패의 원인.
